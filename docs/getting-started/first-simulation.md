# Your first simulation

:::info
This page is a placeholder. Complete, runnable examples are available in the
[examples directory](https://github.com/FEAScript/FEAScript-core/tree/main/examples) of FEAScript-core.
:::

A FEAScript simulation typically consists of the following steps:

1. Create a `FEAScriptModel`.
2. Select the solver and the physics model.
3. Define the mesh configuration.
4. Apply the boundary conditions.
5. Solve and post-process the results.
